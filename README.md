# Every Episode Ranked — production HQ

Open **`dashboard.html`** in your browser (double-click it). That's the home screen.

| Folder | What's in it |
|---|---|
| `guides/` | CapCut guides for this channel (style sheet, voiceover, reusable templates) |
| `research/` | Fandom research plan, video ideas, format decisions |
| `shows/trailer-park-boys/episodes.json` | Every episode: facts, IMDb fan scores, your scores/notes, status |
| `shows/trailer-park-boys/notes/` | Your raw watch notes, one file per episode (`_TEMPLATE.md` is the blank) |
| `shows/trailer-park-boys/extended-universe.json` | Spin-offs, webisodes, animated — parked for later |
| `scripts/` | Shorts + season video scripts |
| `visual-plans/` | Shot-by-shot visual plans |
| `assets-needed/` | Running list of graphics/b-roll to make or find |
| `metadata/` | Titles, descriptions, tags, thumbnail concepts |
| `calendar/` | Posting schedule |
| `tools/` | Theodore's helper that refreshes the dashboard. You never need to run it. |
